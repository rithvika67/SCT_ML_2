Customer Segmentation using K-Means Clustering

This project uses the Mall Customers dataset to group customers based on their Annual Income and Spending Score using the K-Means clustering algorithm.

Tools Used:
- Python
- Pandas
- Matplotlib
- Scikit-learn

Dataset:
- Mall_Customers.csv

Outcome:
Customers are segmented into different groups, helping businesses understand customer behavior and target marketing strategies effectively.
